# Alfa Trade Club (v6.0.1-Mod2Fix) — Android APK Projesi

Bu paket, `botv6.0.1_mod2_duzenlenmis.py` dosyasının tüm strateji motoru (`1. Mod` / `2. Mod`, `Kırılım Yoksa Swing Yoktur`, `OB/OTE/FVG/QML/Likidite`) ve `islem_gecmisi.json` verileriyle birlikte **Android APK** olarak derlenmeye hazır Flet sürümüdür.

## GitHub'a Yükleme ve APK Üretme Adımları
1. Bu ZIP içindeki tüm dosyaları (`.github/workflows/main.yml`, `main.py`, `pyproject.toml`, `requirements.txt`, `islem_gecmisi.json`, `README.md`) klasör yapısını koruyarak GitHub reponuza yükleyin (`Upload files` veya `git push`).
2. GitHub reponuzda **Actions** sekmesine tıklayın.
3. **Android APK Olustur (Flet)** iş akışını çalıştırın (veya `main` dalına yüklediğinizde otomatik başlar).
4. İşlem tamamlandığında sayfanın altındaki **Artifacts** bölümünden `Alfa-Trade-Bot-Android-APK` dosyasını indirip telefonunuza kurabilirsiniz.
